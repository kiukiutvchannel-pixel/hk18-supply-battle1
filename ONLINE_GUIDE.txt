香港十八區動物補給戰 v0.7 — 手機及網上連機版

快速開始
1. 解壓整個 ZIP，保留 dist 目錄結構。
2. 電腦／主機安裝 Node.js 20 或以上。
3. 在解壓目錄執行 npm start；Windows 可雙擊 START_ONLINE_WINDOWS.bat。
4. 電腦開 http://localhost:3000 。同一 Wi-Fi 的手機開 http://電腦的區域網絡IP:3000 。如系統防火牆詢問，允許私人網絡的 Node.js 連線。
5. 房主選地圖，按「開房」。其他人使用同一網址，輸入六位房號按「加入」。全部入齊後，房主按「人齊，開始對戰」。最多四人，每人一隊，空位由 AI 控制。

放上網
將整個解壓內容放到支援長時間執行 Node.js 的網站主機：
啟動指令：npm start
環境變數：PORT（主機指定即可，預設 3000）
監聽：0.0.0.0；遊戲及 /api 同一網域同一服務。
亦附 Dockerfile：docker build -t hk18 .
docker run --rm -p 3000:3000 hk18
在主機提供的 HTTPS 網址開遊戲，分享該網址及房號。普通手機瀏覽器即可加入，手機不用安裝 Node.js。
不要只上傳 dist 到純靜態空間：那樣只可單機，不能開房。GitHub Pages／純檔案伺服器不會執行 server.mjs。
部署只開一個服務實例／一個 Node.js 行程。房間儲存在記憶體，主機重啟會清空；30 分鐘無人連線會移除房間。最多 16 房，尚未做大量玩家負載測試。

手機操作
左搖桿移動；右側長按攻擊／拋箱；搬箱鍵拾放及交付箱子。
使用／開箱鍵開補給箱、駕駛載具及離機；跳躍鍵亦可改直昇機高度。
「建造／隊友」顯示或收起建造面板，可選箱子形狀、開台及自動計劃。
支援獨立指標的搖桿與攻擊；橫向及直向、螢幕安全邊界已調整。
暫停只停止自己的操作，伺服器對戰繼續。離開或背景一段時間後由 AI 接手；可用原本頁面重新整理，保留房間網址及同一分頁的通行證。離房按鈕清除通行證，不會保留重連身份。

已驗證
22 項 HTTP 連機測試通過：四人分隊、房主權限、各隊獨立建造、伺服器移動、操作確認及去重、斷線停步、AI 接手、重連及換人。另通過既有地圖／規則／模型檢查。
兩個瀏覽器畫面實際開房、加入、共同開始；390×844 手機尺寸排版檢查。

未驗證及限制
未以真實 iPhone／Android、多點觸控硬件及公開 HTTPS 主機跨網絡實測。測試瀏覽器無 WebGL，使用有標示的 2.5D 相容模式；完整 3D 需要 WebGL 2。
本包可部署連機伺服器，但既有 ChatGPT Site 仍是靜態展示，未部署 server.mjs，不能將該網址當成已運行的公開連機房。
伺服器 30Hz、HTTP 輪詢約 15Hz，網絡延遲會影響操作流暢度，沒有客戶端預測。無帳戶、積分、語音、跨伺服器配對及永久存檔。
玩法及美術為原創測試遊戲，參考箱子建造玩法，不是 Team Buddies 官方遊戲或完整重製。
