# 香港十八區動物補給戰 v0.7.0

手機觸控修訂＋四人房號連機。`npm start` 啟動包含遊戲與 API 的 Node.js 伺服器；詳見 [ONLINE_GUIDE.txt](ONLINE_GUIDE.txt)。純靜態 Site 只提供單機，公開連機需部署本包的伺服器。

`npm run test:online`：22 項實際 HTTP 整合檢查。單服務、單行程、記憶體房間；30Hz 模擬／約15Hz HTTP 輪詢，未做公開 HTTPS 跨網絡實測。

十八張可選四方地形戰場，加入隨機巨型補給箱、可駕駛機械人及直昇機。預設荃灣區；主選單選區後按「載入所選地圖」。暫停選單可返回選圖。

每張共用北／東／南／西四方基地及中央補給骨架，每隊開局一隻動物。各區使用各自的四個藝術化地標模型，並有獨立高低差參數、地表配色及環河／海岸／山林／岩谷主題；不是按真實地理比例重建十八區。

## 隨機載具

首次巨型空投在開局 12–20 秒左右出現，其後每隔 45–65 秒。兩張隨機順序牌輪流安排機械人及直昇機，避免只重複一種。

箱子落地後，F 開箱，再 F 駕駛；電腦隊伍亦可爭奪。機械人有步行及火箭炮。直昇機自動起飛，WASD／搖桿飛行，R 切換飛行高度，空白鍵攻擊，F 在安全空地降落離機。河道或建築上方拒絕降落，降落期間停止水平移動。

## 驗證

`npm test`：33 項既有規則案例及 4 局模擬；18 地圖各自驗證單人開局、四方通路、隊友搬箱及實際 GLB 解析；6 項隨機載具、起飛、越河、射擊及降落案例。另檢查四款動物與七款武器／載具／補給 GLB。

瀏覽器檢查荃灣、離島、油尖旺選圖與相容模式啟動、全圖及空投倒數，並實際觀察到巨型箱先後開出直昇機與機械人。機械人／直昇機完整操作由規則核心測試驗證；完整 WebGL、手機實機、載具實機 FPS 尚未驗證。

## 檔案

- dist/maps.js：十八區地圖清單。
- dist/assets/maps/01–18/：各區 scene.glb、壓縮檔、碰撞、地圖資料及預覽。
- dist/assets/maps/HK18_Arena_Overview.jpg：十八區總覽。
- dist/special-models.js：機械人、直昇機及巨型箱原創幾何模型。
- dist/assets/weapons/：可匯入其他引擎的 GLB。
- dist/engine.js：共用遊戲規則。
- dist/terrain.js：當前地圖高度、河道／岩谷及通行規則。
- dist/validation.json、test-results.txt：驗證報告。

## 界線

這是原創動物及香港美術的單局對戰，並非 Team Buddies 官方產品或完整重製。戰役、其他原作兵種／載具、完整皮膚骨架動畫未製作；多人連線是本版新增的簡化房號對戰。載具及飛行採簡化操控，未還原原作全部碰撞、運輸及精確數值。相容模式是有標示的 2.5D；原生 3D 需 WebGL 2。
